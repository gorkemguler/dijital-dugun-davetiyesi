## ✨ Öne Çıkan Özellikler

1. **🎨 6 Farklı İnteraktif Tasarım Şablonu & Canlı Önizleme**
   - **Saray Zarafeti (`royal-palace`)**: Fildişi mermer, altın varak işlemeler ve klasik lüks tipografi.
   - **Bohem Botanik (`bohemian-garden`)**: Adaçayı yeşili, sıcak toprak tonları ve kır düğünü estetiği.
   - **Modern Editorial (`modern-editorial`)**: Dergi kapaklarını andıran yüksek kontrastlı minimalist tasarım.
   - **Gece Galası (`midnight-gala`)**: Gece laciverti, rose-gold ışıltılar ve otel/balo salonu atmosferi.
   - **Ege Esintisi (`aegean-breeze`)**: Alaçatı & Akdeniz mavisi, keten beyazı ve sahil düğünü ferahlığı.
   - **Romantik Şakayık (`romantic-blossom`)**: Pudra pembe, gül kurusu detaylar ve dökülen çiçek yaprakları.

2. **🗺️ Esnek Düğün Kurgusu (Tek İl / İki İl / Çoklu Etkinlik)**
   - **Tek İlde Düğün**, **İki İlde Düğün (Örn: 1. İl İzmir Kına + 2. İl İstanbul Gelin Alma, Nikah, Düğün & After Party)** veya **Nikah + Kokteyl + After Party** kurgularını tek tıkla uygulayabilirsiniz.
   - Her etkinlik kartında **Google Haritalar**, **Apple Harita**, **Yandex Navigasyon**, **Kart İçi Canlı Harita** ve **Google/Apple Takvime Ekle** özellikleri hazır gelir.

3. **🛡️ Moderasyonlu Ortak Fotoğraf & Video Albümü (QR Kodlu)**
   - Misafirleriniz hiçbir yere üye olmadan doğrudan davetiye üzerinden fotoğraf (`JPG`, `PNG`, `WEBP`, `HEIC`) ve video (`MP4`, `MOV`, `WEBM`) gönderebilir.
   - **3 Farklı Görünürlük & Güvenlik Modu:**
     - `🛡️ Yönetici Onaylı Gösterim (Önerilen)`: Yüklenen fotoğraf/videolar siz yönetici panelinden onaylayana kadar sayfada kimseye gösterilmez.
     - `🔒 Sadece Gelin & Damat Görsün (Tam Gizli Arşiv)`: Yüklenen medyalar yalnızca sunucunuzdaki `uploads/` klasörüne kaydedilir, sayfada yayınlanmaz.
     - `🌐 Anında Herkese Açık Göster`: Yüklenen medyalar anında Ortak Albüm Duvarında sergilenir.
   - **Masa PIN Kodu Koruması:** İsteğe bağlı PIN kodu belirleyerek yalnızca düğün salonundaki davetlilerin yükleme yapmasını sağlayabilirsiniz.

4. **🔐 Yönetici Şifresi Korumalı Kurulum & Yayına Alma**
   - Kurulumu tamamlayıp **Yönetici Şifrenizi** belirleyerek **"Kaydet & Yayına Al"** butonuna bastığınızda kurulum paneli misafirlere tamamen kapanır.
   - Yönetici olarak istediğiniz zaman sayfanın en altındaki **Yönetici** kilit ikonundan veya `?yonetim=1` adresinden şifrenizle giriş yaparak ayarları değiştirebilir, **Gelen LCV Listesini Excel/CSV** olarak indirebilir ve **Ortak Albüm** medyalarını onaylayıp indirebilirsiniz.

## 🚀 Hızlı Kurulum (Bilgisayar veya Raspberry Pi)

```bash
# 1. Depoyu klonlayın
git clone https://github.com/gorkemguler/dijital-dugun-davetiyesi.git
cd dijital-dugun-davetiyesi

# 2. Bağımlılıkları yükleyin
npm install

# 3. Üretim (Production) derlemesini oluşturun ve sunucuyu başlatın (Varsayılan Port: 4173)
npm run build
npm start
```

Tarayıcınızdan **`http://localhost:4173`** adresini açın:
1. Karşınıza doğrudan **İlk Kurulum Sihirbazı** gelecektir.
2. 1 ile 5 arasındaki sekmelerden şablonunuzu, gelin & damat bilgilerini, etkinlik saat/konumlarını, IBAN hesaplarını ve ortak albüm ayarlarını özelleştirin.
3. Sağ üstteki kutucuğa **Yönetici Şifrenizi** yazıp **"Kaydet & Yayına Al"** butonuna tıklayın!

## 🌐 Cloudflare Tunnel İle İnternete Açma (Yayına Alma) Rehberi

Modeminizde port açmaya (Port Forwarding) veya statik IP almaya gerek kalmadan, ücretsiz **Cloudflare Tunnel (`cloudflared`)** ile davetiyenizi dakikalar içinde kendi alan adınızla (`https://dugun.alanadiniz.com`) veya hızlı test linkiyle yayına alabilirsiniz:

### Yöntem A: Hızlı Geçici Link İle Anında Test
```bash
cloudflared tunnel --url http://localhost:4173
```

### Yöntem B: Kendi Alan Adınızla (7/24 Kalıcı Yayın & 250 MB Video Yükleme)
> 💡 **Önemli İpucu:** Cloudflare Ücretsiz (Free) planında standart proxy üzerinden tek seferlik HTTP POST boyutu 100 MB ile sınırlıdır. Uzun 4K videoların sorunsuz yüklenmesi veya kendi alan adınızı bağlamak için:
```bash
# 1. Cloudflare hesabınıza giriş yapın
cloudflared tunnel login

# 2. "dugun-davet" adında bir tünel oluşturun
cloudflared tunnel create dugun-davet

# 3. Alan adınızı tünele yönlendirin
cloudflared tunnel route dns dugun-davet dugun.alanadiniz.com

# 4. Tüneli başlatın (Arka planda servis olarak kurmak için: sudo cloudflared service install)
cloudflared tunnel run --url http://localhost:4173 dugun-davet
```

## 🍓 Raspberry Pi 4B (2GB RAM + 64GB SD Kart) Performans & Güvenlik Mimari Notları

Bu proje **Raspberry Pi 4B (2GB RAM, 64GB SD Kart)** ve **1000 Mbps Download / 50 Mbps Upload** ev interneti üzerinde yüzlerce davetliye aynı anda kesintisiz hizmet verecek şekilde özel olarak optimize edilmiştir:

- **Sıfır RAM Şişmesi (Streaming Disk Yazımı):** Misafirlerin gönderdiği büyük boyutlu videolar (250 MB'a kadar) RAM'e alınmaz (`Buffer` biriktirilmez); Node.js `fs.createWriteStream` ile doğrudan SD karta akıtılır. 2 GB RAM'li Raspberry Pi'de bellek kullanımı **~55–65 MB** seviyesinde sabit kalır.
- **64 GB SD Kart İçin 50 GB Akıllı Albüm Kotası:** 64 GB SD kart tamamen bu projeye ayrıldığında işletim sistemine ~7–8 GB güvenli alan bırakılarak **50 GB albüm kotası** ve **10.000 medya sınırı** tanımlanmıştır (Yönetici panelinden istediğiniz zaman değiştirilebilir ve canlı doluluk çubuğundan takip edilebilir).
- **Binary Magic Bytes (Dosya İmzası) Doğrulaması:** Yüklenen her dosyanın ilk 16 byte'lık binary imzası (`FF D8 FF` JPEG, `89 50 4E 47` PNG, `ftyp` MP4/MOV/HEIC, `1A 45 DF A3` WEBM) incelenir; uzantısı değiştirilmiş zararlı script veya çalıştırılabilir dosyalar diske yazılmadan reddedilir.
- **Kriptografik Şifre & Oturum Güvenliği:** Yönetici şifresi asenkron `crypto.scrypt` + rastgele `salt` ile özetlenir ve `crypto.timingSafeEqual` ile doğrulanır.
